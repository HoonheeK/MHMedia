# MHMedia Player

Tauri v2 + Rust + React + TypeScript 기반의 데스크톱 미디어 플레이어입니다.  
MP3, WAV, FLAC 등의 오디오 파일과 MP4, WebM, MKV 등의 비디오 파일을 감상할 수 있습니다.

---

## ✨ 주요 기능

1. **오디오 & 동영상 통합 지원**
   - **오디오 포맷**: MP3, WAV, FLAC, OGG, AAC, M4A, WMA
   - **동영상 포맷**: MP4, WebM, MKV, MOV, AVI, WMV, FLV
   - 오디오 재생 시 **실시간 캔버스 이퀄라이저 파형 애니메이션(Visualizer)** 및 회전 바이닐 디스크 효과 제공
   - 동영상 재생 시 **화면 비율 유지 및 전체화면 모드(F)** 지원

2. **파일 및 폴더 탐색 & 드래그 앤 드롭 (Drag & Drop)**
   - **드래그 앤 드롭(Drag & Drop)**: 탐색기에서 오디오/비디오 파일이나 폴더를 앱 창으로 끌어다 놓으면 즉시 재생목록에 자동 등록
   - 파일 선택 창을 통한 다중 파일 추가 (`@tauri-apps/plugin-dialog`)
   - 폴더 통째로 스캔하여 미디어 파일 일괄 등록 기능 (Rust 백엔드 `scan_media_folder`)
   - 파일별 포맷 태그 및 용량 정보 표시

3. **풍부한 재생 제어 (Player Controls)**
   - 재생 / 일시정지
   - 이전 / 다음 트랙 이동
   - 5초 뒤로 / 5초 앞으로 이동
   - 실시간 시크바 (진행률 탐색)
   - 볼륨 슬라이더 및 음소거 토글
   - 배속 조절 (0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x)
   - 반복 모드 (끄기 / 전체 반복 / 한 곡 반복)
   - 셔플 재생 (랜덤)

4. **재생목록 관리 (Playlist Panel)**
   - 미디어 검색 필터링
   - 트랙 선택 즉시 재생
   - 개별 트랙 삭제 및 전체 목록 비우기
   - 사이드바 접기/펼치기 지원

5. **키보드 단축키 지원**
   - `Space`: 재생 / 일시정지 (화면 중앙 OSD 표시)
   - `←` / `→`: 5초 뒤로 / 앞으로 이동 (화면 중앙 OSD 표시)
   - `↑` / `↓`: 볼륨 조절 (5% 단위 OSD 표시)
   - `M`: 음소거 전환
   - `F`: 전체화면 토글
   - `L`: 재생목록 사이드바 열기/닫기
   - `N`: 다음 미디어 재생
   - `P`: 이전 미디어 재생
   - `R`: 반복 모드 전환

6. **마우스 제스처 (Mouse Controls)**
   - **화면 1회 클릭**: 재생 / 일시정지
   - **화면 더블 클릭**: 전체화면 진입 / 해제
   - **마우스 휠 스크롤**: 뷰어 화면에서 위/아래 휠로 볼륨 조절
   - **전체화면 오버레이**: 재생 바가 높은 투명도의 플로팅 바로 화면 위에 표시되며, 2.5초간 마우스 조작이 없을 시 컨트롤 바와 커서가 자동으로 부드럽게 숨겨집니다.

7. **✨ 파일 상태 맞춤 스마트 어시스턴트 (Smart Assistant & Modeless Window)**
   - 미디어 파일의 유형과 상태를 자동으로 분석하여 뷰어 우상단에 맞춤 제안 칩(버튼) 제공
   - **모달리스(Modeless) 플로팅 윈도우**: 어시스턴트 창이 열린 상태에서도 뒤편의 플레이어 조작 및 재생목록 클릭 가능. 상단 헤더를 드래그하여 자유롭게 이동 및 창 크기 조절/최대화 지원.
   - **다국어 지원**: 한국어(KO), 영어(EN), 일본어(JA) 언어 팩 지원.
   - **초고속 AI 전사 (재생 없이 추출)**: Groq Whisper / OpenAI API와 연동하여 소리를 재생하지 않고 1~2초 만에 백그라운드에서 전체 대본/자막 고속 추출.
   - **📋 단일 통합 복사 버튼 (Unified Copy)**:
     - 드롭다운 일체형 단일 버튼으로 손쉽게 전환 대응
     - `📄 텍스트만 복사`: 타임코드를 제외한 순수 텍스트만 클립보드에 복사
     - `⏱️ 시간 + 텍스트 복사`: 타임스탬프(`[00:01:23]`)를 포함한 전체 대본을 클립보드에 복사
   - **🎵 음악 파일**: 곡명/아티스트 기반 실시간 가사(Lyrics) 조회, 재생 시간 연동 타임싱크 가사 하이라이트 및 소절 클릭 시 즉시 탐색(Seek)
   - **🎬 동영상 파일**: 재생 없는 고속 음성 대본 추출 및 대본 항목 클릭 시 해당 비디오 구간 즉시 점프 이동

## 🚀 실행 및 개발 방법

### 개발 모드 실행
```bash
npm run tauri dev
```
또는 프론트엔드 UI만 브라우저에서 확인할 경우:
```bash
npm run dev
```

### 프로덕션 빌드 (Windows 설치/실행 파일)
```bash
npm run tauri build
```
빌드 완료 후 `src-tauri/target/release/` 또는 번들러 디렉토리에 설치 파일(`.exe` / `.msi`)이 생성됩니다.

---

## 🛠 기술 스택
- **Desktop Framework**: Tauri v2
- **Backend**: Rust (Edition 2024), `tauri-plugin-dialog`, `protocol-asset`
- **Frontend**: React 19, TypeScript, Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Modern Dark Glassmorphism)
